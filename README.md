# 🎮 Tic Tac Toe (Tres en Raya)

Proyecto en **Java** que implementa el clásico juego de Tic Tac Toe (Tres en Raya) jugable desde la terminal.

---

## 📌 Descripción
Dos jugadores (`X` y `O`) se enfrentan en un tablero de 3x3.  
- El jugador `X` siempre empieza.  
- Gana quien logre alinear tres símbolos en fila, columna o diagonal.  
- Si se llena el tablero sin ganador, se declara empate.  

---

## 🛠 Tecnologías y Herramientas
- **Java 21**
- **Visual Studio Code**
- **Git / GitHub**
- **Trello** (planificación y seguimiento)

---

## 🚀 Ejecución del proyecto

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/<tu-usuario>/tic-tac-toe.git
   cd tic-tac-toe
   
2. Compilar
   ```bash
   javac TicTacToe.java

3. Ejecutar:
   ```bash
   java TicTacToe

## 📋 Requisitos funcionales

- Mostrar el tablero vacío al inicio.
- Mostrar el estado del tablero después de cada movimiento.
- Permitir jugar por turnos (X inicia).
- Ingresar movimientos por fila y columna.
- Validar si la celda está vacía antes de jugar.
- Detectar ganador tras cada movimiento.
- Detectar empate si el tablero se llena.
- Mostrar mensaje final de victoria o empate.

## 🔄 Metodología

Pair programming con rotación de roles:

- Driver: escribe código
- Navigator: guía y revisa
- Timekeeper: controla tiempos y cambios de rol
